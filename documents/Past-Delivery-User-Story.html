Section 01

User Story

Primary Story
"As a rider, I want to view a paginated list of my past deliveries (both completed and failed), filtered by date range and delivery status, so that I can track my delivery history and earnings."
  • AC-1: Only deliveries in Delivered (status 4) or Failed (status 5) state are shown.
  • AC-2: Results are scoped strictly to the authenticated rider — no cross-rider data leakage.
  • AC-3: Rider can filter by date range (from / to) and optionally by status (Delivered, Failed, or All).
  • AC-4: Results are paginated (10 per page) with Prev / Next controls and a total count summary.
  • AC-5: Each card shows: Order #, Customer name, Delivery address, Earnings (INR), timestamps, and a delivery timeline (Assigned → Picked Up → In Transit → Delivered).
  • AC-6: If no deliveries match the filter, an empty-state message is shown instead of an empty table.
  • AC-7: Unauthenticated requests to the API endpoint return 401 Unauthorized.

Section 06

Component Architecture

Frontend — Angular Files

FileRole
rider-past-deliveries.component.ts Standalone component. Manages filter state (dateFrom, dateTo, statusId), pagination, and reactive UI state via Angular signal().
rider-past-deliveries.component.html Template with filter bar, loading/error/empty states, delivery card list, and pagination nav.
rider-past-deliveries.component.css Scoped styles. Glassmorphism cards, status badge colours, timeline strip.
rider-api.service.ts Injectable service. getPastDeliveries(filter) builds HttpParams and calls GET /api/rider/past-deliveries with credentials.
rider.models.ts TypeScript interfaces: PastDelivery, PastDeliveriesResponse, PastDeliveriesFilter, DeliveryStatusId enum.

Backend — C# Files

FileRole
RiderPortalApiController.cs REST controller. Validates auth + rider ownership, clamps pagination params, parses date filters to UTC, delegates to service, and shapes the JSON response.
DeliveryOrderService.cs GetPastDeliveriesAsync(): Queries the DeliveryOrder repository filtered by riderId, past statuses (4 or 5), optional date range, and optional statusId. Returns paginated (IList<DeliveryOrder>, totalCount) tuple.
IDeliveryOrderService.cs Interface contract defining GetPastDeliveriesAsync() signature.
DeliveryOrder.cs (entity) EF Core entity with timestamp fields: AssignedAtUtc, PickedUpOnUtc, InTransitOnUtc, DeliveredOnUtc.

Section 08

Security & Data Isolation

ConcernHow It Is Handled
AuthenticationController calls GetAuthenticatedCustomerAsync() — returns 401 if no valid session.
Rider ownershipRider record is fetched by customerId of the logged-in user. Query always includes WHERE riderId = <authenticated riderId>.
Cross-rider accessImpossible — the riderId used in the DB query is derived from the server-side session, never from a user-supplied parameter.
Pagination abusepageSize is clamped server-side to 1–50; pageIndex is clamped to ≥ 0.
Date injectionDates are parsed via DateTime.TryParse and re-specified as UTC — raw strings are never passed to the query engine.
